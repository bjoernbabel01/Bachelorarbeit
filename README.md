# Bachelorarbeit
"ESP32_Programm"

Im Ordner "ESP32_Programm" befindet sich das Programm für den ESP32-Mikrocontroller des Tangibles der Interaktionsvariante TUI mit Datenphysikalisierung. Für eine Reproduktion der Studie müssen gegebenenfalls die WLAN-SSID, das WLAN-Passwort sowie der verwendete UDP-Port angepasst werden.

"Studie"

Der Ordner "Studie" enthält die für die Durchführung und Auswertung der Studie relevanten Dateien. Dazu gehören die Einverständniserklärung sowie die im Hintergrund aufgezeichneten Interaktionen der einzelnen Studienteilnehmenden im Unterordner "Aufzeichnungsdateien".

Darüber hinaus enthält der Ordner die Studienergebnisse und Auswertungen. Die Ergebnisse der SoSci-Survey-Erhebung sind in der Datei "Studienergebnisse_SoSci_Survey" sowie in den zugehörigen JASP-Dateien abgelegt.

"Unity Build"

Der Ordner "Unity Build" enthält den Unity Build der Anwendung, die für die Durchführung der Studie verwendet wurde.

"Unity Projekt"

Der Ordner "Unity Projekt" enthält das entwickelte Unity-Projekt der Simulation.
